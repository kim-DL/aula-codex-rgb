# 소스 스냅샷 확인

2026-10-25에 사용자가 확정한 파랑 배경·흰색 코드 스캔과 문서 읽기 기능을 포함한 소스입니다.

새 Git 작업 폴더에서 `Build.ps1 -Candidate`로 검사 및 빌드했고, 원래 설치 위치에서 실행 중인 파일과 다음 SHA256이 **바이트 단위로 일치**했습니다.

| 파일 | SHA256 |
| --- | --- |
| GUI | `39104380953BA30BC33236F8F6ADE3D2ECA31B379465A372FAA6BF2B908E83E0` |
| CLI | `655138B4F9EDE7F46908D68B3FE9DB71554DCF08E811CE0F4D42F50010CE94CC` |

확인 환경은 Windows amd64 / Go 1.27.2이며 빌드 플래그는 `-buildvcs=false -trimpath`, CLI `-s -w`, GUI `-s -w -H=windowsgui`입니다. 다른 Go 버전의 결과 파일은 동작이 같아도 해시가 달라질 수 있습니다.

실행 파일 자체는 Git에 올리지 않습니다. 현재 설치와 백업은 원래 위치에 유지하고 이 저장소는 별도의 소스 작업 폴더입니다. 테스트의 대화 식별자 한 곳은 합성 상수로 익명화했으며 실행 코드에는 영향을 주지 않습니다.

검사:

- 수정된 드라이버의 선택된 realtime mock 검사 통과.
- `app`: `go test ./...`, `go test -tags rgb_gui ./...` 통과.
- 현재 실행 파일·설정·자동 실행·USB 연결은 업로드 작업에서 변경하지 않음.
