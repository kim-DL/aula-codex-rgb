# 구현 구조

## 이벤트와 상태

현재 사용자 named pipe로 짧은 훅 메타데이터를 전달하고, 로컬 rollout JSONL을 읽기 전용으로 추적합니다. 임시 세션은 명시적인 임시 메타데이터로 제외합니다. 중복과 역순 이벤트, 동시 도구·승인, 확정/추정을 구분합니다. `Stop`은 완료 힌트이며 실제 턴 종료와 구분합니다.

읽기 분류는 입력을 메모리에서 제한된 크기로 한 번 검사합니다. 지원되는 읽기 도구는 명시적인 읽기로, 단순 셸·도구 래퍼는 추정으로 표시합니다. 읽기 상태와 수정 상태는 구분하되 흰색 문서 파동을 공유합니다. 임의 스크립트를 실행해 분류하지 않습니다.

## 효과와 전송

렌더러는 104개 키의 검증된 유선 주소·기하를 사용합니다. 기본 65%·10fps이며 코드 스캔은 파란 배경과 중립 흰색, 뒤쪽 약 한 키의 잔광을 사용합니다. 움직임은 경과시간 기반입니다. 실제 파일 저장률·줄 번호 진행률은 표시하지 않습니다.

HID interface 3 / FF13의 단일 연결만 소유합니다. 초기 펌웨어 준비를 애니메이션 시작 전에 끝내고, 기존 프로토콜의 대기 시간은 유지합니다. Windows가 낮은 우선순위를 상속시킨 경우에만 시작 시 기본 Normal로 복구합니다. 전역 전원·타이머 설정은 변경하지 않습니다.

주 실행 경로에는 프로필 저장·플래시 저장을 넣지 않습니다. upstream 및 개발 도구에는 별도의 저수준 기능이 있으므로 하드웨어 검사는 상주 앱과 동시에 실행하지 마세요.

## LCD

단일 USB 루프가 RGB 프레임 사이에서 RTC 트랜잭션을 직렬 실행합니다. 시작·종료·재연결·날짜 변경 등에 동기화하고 초는 키보드 RTC가 증가시킵니다. 완료 값을 고정하려고 반복 쓰지 않습니다. 최근 결과는 RAM의 값 하나뿐이며 health·설정·진단 파일에 소요시간을 저장하지 않습니다.

## 로컬 데이터

실제 설정·기술 상태는 현재 사용자의 `%LOCALAPPDATA%\AulaCodexRgb`, 훅은 사용자 `.codex/hooks.json`을 이용합니다. 이 파일들은 Git에 포함하지 않습니다. 복원용 사용자별 묶음은 원래 PC에 별도로 유지합니다.
