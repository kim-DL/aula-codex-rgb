# 검증 범위와 현재 스냅샷

## v0.1.1 더블클릭 설치 도구

- 기존 RGB·LCD GUI와 CLI는 v0.1.0 확정 파일과 SHA256이 같은 파일을 배포합니다. 한국어 안내용 setup EXE와 Install.cmd / Run.cmd / Uninstall.cmd만 추가합니다.
- 설치·실행·제거 순서, 다른 위치의 자동 실행 등록 보호, 등록 조회 실패, 설치 실패, 종료 실패·시간 초과 시 제거 중단을 모의 작업으로 검사했습니다. 실제 사용자 훅·레지스트리·실행 중 앱을 바꾸지 않는 검사입니다.
- 실제 Windows CMD에서 한글·공백·앰퍼샌드가 있는 경로의 세 런처를 실행하고 올바른 실행 파일·작업 전달 및 성공/실패 종료 코드 6개 조합을 확인했습니다. 실행 대상은 무해한 기록용 EXE입니다.
- `Build.ps1 -Candidate`의 앱·GUI 검사와 모의 실시간 패킷 검사 및 setup 빌드를 통과했습니다. 새 PC의 깨끗한 사용자 계정에서 설치·훅 신뢰 등록·로그인 자동 실행을 직접 확인한 결과로 확대하지 않습니다.
- 재현: `scripts/Test-Launchers.ps1 -GoExe <go.exe 경로>`와 `Build.ps1 -Candidate -GoExe <go.exe 경로>`를 일반 개발 PowerShell에서 실행합니다.

2026-10-25에 사용자 확인을 마친 **파란 배경·짧은 흰색 코드 스캔 + 문서 읽기 기능**을 소스로 보관합니다.

## 현재 기능 확인

- 문서·소스 파일을 실제로 읽을 때 기존 흰색 문서 파동을 관찰했고, 사용자가 LCD·타이핑 정상도 확인했습니다.
- 코드 효과를 파랑+흰색 스캔으로 변경한 후 실제 키보드로 약 30초 시연했습니다. 해당 구간의 USB 전송·적용 오류 증가는 0건이었습니다.
- 흰색 중심·파란 바탕·짧은 잔광·행 전환 연속성·F1~F12 참여·65% 상한을 자동 검사합니다. 기존 생각 중 및 다른 상태 검사도 보존합니다.
- LCD 작업 중 카운트와 실제 로컬 요청 완료 후 PC 시각 복귀는 이전 실기로 확인했으며 이후 시각 효과 변경은 LCD 코드를 바꾸지 않았습니다.

## 과거 안정성 자료와 구분

이전 우선순위 개선판의 실제 600초 관찰에서는 5,979프레임, 95/99백분위 상한 46ms, 최대 구간 상한 68ms, 100ms 초과·USB 오류·재연결 0건이었습니다. 이는 이후 읽기/색상 효과 변경 전 파일의 자료이며 **현재 파일의 새로운 10분 시험 결과로 표현하지 않습니다**.

과거 실제 USB 재연결·절전 복귀는 사용자 확인을 포함해 수행했습니다. 모든 소프트웨어 버전에서 이 조건을 매번 재검증한 것은 아닙니다. 일반 ChatGPT 단독 연동은 실제 시험에서 신호를 확인하지 못해 지원 범위로 주장하지 않습니다.

개별 실기 원본·사용자 설정·대화 식별자는 이 저장소에 올리지 않습니다. 검사 결과를 시각 만족도나 장기 무오류 보장으로 확대하지 않습니다.
