# AULA Codex RGB

Windows에서 USB-C 유선 AULA F108 Pro의 키별 RGB와 기본 LCD 시계를 로컬 Codex·Work 작업 상태에 연결하는 Go 앱입니다.

현재 확정 기준은 **밝기 65%·10fps**, **파랑 배경의 짧은 흰색 코드 스캔**, **문서 읽기 흰색 파동**입니다. F1~F12도 전체 효과에 참여하며 별도 작업 상태 배지는 없습니다.

| 상태 | 표시 |
| --- | --- |
| 생각 중 추정 | 파랑·흰색 생명 파동 |
| 코드 작성·수정 | 파란 배경, 짧은 흰색 스캔과 뒤쪽 약 한 키 잔광 |
| 문서·파일·자료 읽기 | 기존 흰색 문서 파동, 짧은 작업은 1.8초 여운 |
| 문서 수정 | 흰색 문서 파동 |
| 일반 도구 실행 | 노랑 이동 효과 |
| 승인·입력 대기 | 노랑/호박색 전체 모션 |
| 완료 / 오류 | 초록 완료 파동 / 빨강 오류 표시 |
| 대기 | 낮은 샌드빛과 흰빛 유영 |

지원되는 명시적 읽기 도구와 단순 본문 조회를 읽기로 분류합니다. 혼합 실행·동적 명령·판별하기 어려운 도구는 일반 실행으로 유지합니다. 트레이에서는 확정·추정 상태를 구분합니다. 생각 중 표시는 내부 사고나 토큰 생성 속도의 직접 측정이 아닙니다.

## LCD

로컬 요청 시작부터 기본 LCD 시계 숫자로 경과시간을 표시하고, 실제 턴 완료·실패·중단 뒤 PC 날짜·시각으로 돌아옵니다. 동시 요청은 가장 최근 요청을 표시합니다. 최근 결과 한 건만 RAM에 보관하며 앱 종료 시 사라집니다. 시간 이력 파일이나 DB는 만들지 않습니다.

## 지원 환경

- Windows 10/11, Go 1.24.5 이상. 이 소스 스냅샷은 Go 1.27.2로 검사합니다.
- AULA F108 Pro USB-C 유선: VID `0C45`, PID `800A`, RGB interface 3 / usage page `FF13`.
- 로컬 Codex·Work 훅과 읽기 전용 세션 기록을 이용합니다. 일반 ChatGPT 모드·클라우드 작업·다른 키보드 모델의 호환성을 보장하지 않습니다.
- 데스크톱 패키지 이름과 이벤트 형식에 의존하므로 제품 업데이트 후 재확인이 필요할 수 있습니다.

## 빌드와 검사

빌드 없이 사용할 Windows x64 실행 파일은 [GitHub Releases](https://github.com/kim-DL/aula-codex-rgb/releases/latest)에서 받습니다. [다운로드·설치 안내](docs/DOWNLOADS.md)를 참고하세요.

PowerShell에서 저장소 루트를 작업 폴더로 사용합니다. Go가 PATH에 있어야 합니다.

```powershell
.\Build.ps1 -TestOnly
.\Build.ps1 -Candidate
.\Build.ps1
```

별도 Go 설치 경로는 `-GoExe 'C:\Tools\go\bin\go.exe'`로 지정합니다. 결과는 `bin/`에 생성합니다. 실행 중인 프로그램과 같은 경로에 빌드할 때는 앱을 정상 종료하거나 `-Candidate`를 사용하세요. 위 검사에서는 키보드를 여는 upstream 하드웨어 테스트를 실행하지 않습니다.

## 설치와 실행

**Windows 시작 메뉴에서 연 일반 PowerShell**에서 실행합니다. Codex 패키지 내부 셸은 AppData와 시작 등록 경로가 가상화될 수 있습니다.

```powershell
.\bin\aula-codex-rgb.exe install
.\bin\aula-codex-rgb.exe run
.\bin\aula-codex-rgb.exe status
.\bin\aula-codex-rgb.exe lcd-status
```

`install`은 현재 사용자 자동 실행과 AULA 훅을 추가합니다. 기존의 다른 훅은 보존합니다. Codex에서 요구하는 훅 검토·신뢰 등록은 제품의 정상 절차로 진행해야 합니다. 신뢰 저장소나 승인 정책을 우회하지 않습니다.

트레이에서 일시 정지·재개·종료가 가능합니다. CLI는 `pause`, `resume`, `stop`, `uninstall`도 제공합니다. `uninstall`은 AULA 연동과 자동 실행 항목을 제거합니다.

## 구조

- `app/`: 상주 앱, 트레이, 상태 엔진, 읽기 분류, LCD 컨트롤러, 애니메이션 및 검사.
- `app/cmd/`: 앱에 포함되지 않는 미리보기·실기·실험 개발 도구. USB/영구 설정 관련 도구는 자동 실행되지 않습니다.
- `upstream/`: 라이선스를 보존한 `parsiya/f108-pro`의 수정된 소스 스냅샷. 중첩 Git 저장소나 서브모듈이 아닙니다.
- [개발·동작 상세](docs/ARCHITECTURE.md), [검증 범위](docs/VALIDATION.md), [서드파티 고지](THIRD_PARTY_NOTICES.md).

오프라인 미리보기는 `app` 폴더에서 `go run ./cmd/preview ../preview`로 생성합니다.

## 장치 및 데이터 처리

정상 실행은 단일 HID 소유자가 연결을 유지하며 휘발성 RGB 프레임과 RTC 동기화를 직렬 전송합니다. 밀린 프레임을 쌓지 않고 시간 기반으로 효과를 계산합니다. 드라이버 교체나 관리자 서비스가 필요하지 않습니다.

정규화 이벤트에는 상태 판별에 필요한 메타데이터만 전달합니다. 문서 내용·명령 전문·대화 본문·LCD 작업 시간 이력을 진단 로그에 추가하지 않습니다. 진단 상세 로그는 기본 비활성입니다. 정상 종료 시 차분한 조명과 PC 시각 복귀를 시도하며 분리·강제 종료 시 복귀를 보장하지 않습니다.

이 저장소에는 소스·합성 검사 자료·일반 안내만 포함합니다. 실제 AppData 설정, 사용자 훅 사본, 개인 경로의 복원 묶음, 대화·실기 로그, 실행 파일과 Go 캐시는 로컬에 별도로 보관합니다.
